## 1. 设计语言

### 1.1 色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 Primary | `#6366F1` 靛蓝 | 品牌、主按钮、链接、导航选中态、用户气泡 |
| 成功 Success | `#10B981` 翠绿 | 已学、成功提示、掌握度高 |
| 警告 Warning | `#F59E0B` 琥珀 | 待学、薄弱警告、推理模型提示 |
| 危险 Danger | `#EF4444` 红 | 删除、失败、掌握度极低 |
| 背景 Background | `#FAFAFA` | 页面底色 |
| 卡片 Card | `#FFFFFF` | 卡片/侧边栏/面板 |
| 主文字 Text | `#1F2937` | 标题、正文 |
| 次文字 Muted | `#6B7280` | 说明、辅助信息 |
| 边框 Border | `#E5E7EB` | 分割线、描边 |

> 知识图谱的节点色沿用现有语义（白箱蓝/黑箱琥珀/待学灰），与整体色板协调。

### 1.2 字体与圆角

- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 圆角：卡片 12px / 按钮 8px / 输入框 8px
- 阴影：卡片 `0 1px 3px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04)`（轻）
- 间距：页面左右 padding 2rem，卡片内 padding 1.25rem

## 3. 实现注意

1. **组件 API 以任务文件「速查」为准**（已实测签名）：
   - `metric_card(label=, value=, delta=)` 单卡，不是列表
   - `card(title=, content=, description=, key=)` 非 context manager
   - `tabs(options=[...], key=)` 用 options
2. **不动逻辑**：所有按钮回调、session_state 键、纯函数一律不改，只换外观容器
3. **样式注入**：全局 CSS 放 main.py 一次性注入；页面级特殊样式用 `stylable_container`
4. **图谱节点色**保持现有语义色（白箱蓝/黑箱琥珀），仅容器美化
5. **验证**：每页改完跑 AppTest 冒烟 + 手动浏览器确认
