# 📚 活书使用教程 — 从入门到精通

> 活书（huoshu）：**把教材变成可交互知识图谱的自学工具**。
> 本文档带你从零开始：5 分钟快速上手 → 完整功能指南 → 配置参考 → 创建自己的知识图谱 → 常见问题。

---

## 一、5 分钟快速上手 🚀

假设你刚接触活书，只想赶紧用起来：

### 第 1 步：安装

```bash
pip install learning-agent
```

需要 Python 3.12+。装好后直接输入：

```bash
huoshu
```

浏览器会自动打开 **http://localhost:8501**（未自动打开就手动访问）。如果端口被占用：`huoshu --server.port 8600`。

> 💡 使用虚拟环境（venv/conda）的记得先激活。Windows 上命令一样，无需额外配置。

### 第 2 步：AI 建图谱（上传书 → 自动生成知识图谱）

1. 打开后默认就在 **🤖 AI 建图谱** 页
2. 选择一个 PDF 教材文件（目录模式）或先去「📖 教材检索」页上传
3. 选择学习目标（考试复习 / 系统读懂 / 快速应用）
4. 点「🤖 AI 生成知识图谱」，等待分阶段生成：
   `解析文本 → 抽取目录 → 逐章抽取知识点 → 连接依赖边`
5. 生成后**校对**：表格里直接改知识点类型/黑白箱、删除不需要的项
6. 点「💾 保存为图谱」，完成！

> 这一步需要配置 LLM（AI 抽取用）。没配的话页面会提示你去「⚙️ 模型设置」填写
> DeepSeek API Key（国内直连，很便宜）。也可以用 Ollama 本地模型（免费）。

### 第 3 步：开始学习

1. 进 **📖 学习会话**，侧边栏选择刚保存的图谱
2. 设定学习目标，跟着 Socratic 引导提问学习（"X 的定义是什么"、"考考我"）
3. 每天进 **🔁 间隔复习** 页做 10 分钟自测，系统自动安排复习节奏

### 第 4 步（可选）：教材检索

1. 进 **📖 教材检索**，把 PDF 拖进页面入库
2. 输入自然语言问题，返回教材原文 + **精确页码引用**

> 这一步需要本地 [Ollama](https://ollama.com) 运行：`ollama pull nomic-embed-text`

## 二、完整功能指南 📖

### 🤖 AI 建图谱页

**这是活书的入口**——把教材变成知识图谱全靠它：

| 环节 | 说明 |
|---|---|
| 选 PDF | 从 `~/.huoshu/pdf/` 选择教材（或先去检索页上传） |
| 学习目标 | 考试复习 / 系统读懂 / 快速应用——影响抽取深度 |
| AI 抽取 | 四层分解：目录→章节→原子知识点；自动判断白箱/黑箱；QUERY 算法连前置边 |
| 校对 | 表格直接改 type/mode、删项；AI 初稿 + 人校对是质量保障 |
| 保存 | 写入 `~/.huoshu/bookmap/`，图谱/学习/复习页立即可用 |

**生成质量提示**：
- 每段最多出 8 个知识点（超出会分段继续抽），生成慢是正常的（一章一次 LLM 调用）
- 校对时重点看：type 分类对不对、该深究的定理有没有标成白箱、多余碎片删掉
- 想更细粒度？把 PDF 按章节拆成多个文件分别生成再合并

### 📊 知识图谱页

| 元素 | 含义 |
|---|---|
| 🟦 蓝色节点 | **白箱**（whitebox）：要求深入理解——能讲证明动机、会做变式题 |
| 🟨 琥珀节点 | **黑箱**（blackbox）：工具型知识——公式记住、会用即可 |
| 边框粗细 | **掌握度**：越粗越稳（🟢≥0.8 🟡≥0.5 🟠≥0.2 🔴<0.2） |
| 菱形 / 椭圆 | 菱形=定理/定义，椭圆=方法/应用 |
| 实线箭头 | 前置依赖（先学这个才能学下一个） |
| 虚线 | 相关概念（类比/对比，横向联系） |

操作：拖拽缩放、点击节点看详情（前置链/相关/后置）、右上角搜索框定位知识点、侧边栏可过滤章节。

### 📖 学习会话页

- **设定目标**：告诉系统你要学什么，它推荐入口节点
- **下钻/返回**：深入某个知识点时自动记 breadcrumb，随时回退，不会迷路
- **三栏导航**：迷航时展示「已完成 / 剩余 / 推荐」，推荐优先给前置就绪 + 薄弱的知识点
- **Socratic 提问**：不直接喂答案，先引导你自己想；提问类型参考：

| 想了解 | 直接问 |
|---|---|
| 概念定义 | "X 的定义是什么" |
| 定理证明 | "X 定理怎么证" |
| 证明动机 | "为什么这样证" |
| 概念关系 | "X 和 Y 什么关系" |
| 前置补缺 | "Z 是什么"（自动定位到前置图谱） |
| 应用场景 | "这个定理有什么用" |
| 自测 | "考考我" |

> 定理表述一律以教材原文为准（防幻觉）；想深入就追问，想快就让它简化——系统会根据你的提问习惯主动建议「深究 / 工具化」切换。

### 📖 教材检索页

- **入库**：上传 PDF（推荐）或从目录选择；分块大小越小检索越细（500 字符默认）
- **检索**：自然语言提问，返回原文 + 页码 + 相似度
- **集合管理**：查看统计、删除集合（需勾选确认）

**检索技巧**：问题越具体越好；同一问题换措辞再搜一次；结合页码回教材精读。

### 🔁 间隔复习页

- 系统按掌握度自动筛选**到期**知识点（答错回炉 1 天，答对逐步拉长 3→7→14→30 天）
- 出题难度自适应：掌握度低→基础题，中→理解题，高→应用题
- 答题后自动更新掌握度（IRT 模型）并重排复习日期
- 建议：每天 10 分钟，比考前突击效率高得多

### ⚙️ 模型设置页

- **提供商**：DeepSeek（默认，国内直连）/ OpenAI / Ollama（本地免费）
- **API Key**：只存在本机 `~/.huoshu/config.json`（权限 600），不上传、不进 git
- **Base URL**：支持自定义中转/代理地址；填 Anthropic 端点会提示不兼容
- **代理**：网络无法直连 API 时填代理地址（如 `http://127.0.0.1:7890`）
- **测试连接**：保存前先验证能不能通

## 三、配置参考 ⚙️

### 环境变量总表

| 变量 | 默认值 | 用途 |
|---|---|---|
| `LLM_PROVIDER` | `deepseek` | LLM 提供商：deepseek / openai / ollama |
| `LLM_API_KEY` | 空 | LLM API 密钥（设置页填了就不用环境变量） |
| `LLM_MODEL` | 按提供商 | 模型名，如 deepseek-chat / gpt-4o-mini |
| `HUOSHU_OLLAMA_URL` | `http://localhost:11434/api/embeddings` | Ollama embedding 端点 |
| `HUOSHU_CHROMA_DIR` | `~/.huoshu/chroma` | 向量库目录 |
| `HUOSHU_PDF_DIR` | `~/.huoshu/pdf` | PDF 教材目录（页面可直接上传，无需手动放） |
| `HUOSHU_BOOKMAP_DIR` | 常见目录 | 知识图谱搜索目录 |

Windows 写法：`set LLM_API_KEY=sk-xxx`（PowerShell：`$env:LLM_API_KEY="sk-xxx"`）。

### Ollama 安装（教材检索需要）

```bash
# Linux / macOS
curl -fsSL https://ollama.com/install.sh | sh

# Windows：官网下载安装包
# https://ollama.com/download

# 拉取 embedding 模型（检索必需）
ollama pull nomic-embed-text

# 可选：本地 LLM（学习会话用，免费）
ollama pull llama3.2
```

验证 Ollama 正常：浏览器打开 http://localhost:11434 能看到响应。

### 数据都存哪

所有用户数据都在 `~/.huoshu/`（不污染项目目录、不进入 git）：

```
~/.huoshu/
├── config.json    # LLM 配置（权限 600）
├── pdf/           # 上传/存放的教材 PDF
├── chroma/        # 向量数据库
└── bookmap/       # 知识图谱文件（可选放这）
```

## 四、创建自己的知识图谱 🗺️

### 方式一：AI 自动生成（推荐）

在 **🤖 AI 建图谱** 页：上传/选择 PDF → 点「AI 生成知识图谱」→ 校对 → 保存。
AI 按四层分解法自动完成：目录抽取 → 逐章原子知识点（含黑白箱标注）→ 前置/相关边。
生成前建议选好**学习目标**（考试/读懂/应用），抽取粒度会更贴合你的需求。

### 方式二：手动创建（进阶）

想完全掌控图谱结构时，可直接写 JSON。格式见 [bookmap-schema.json](../framework/bookmap-schema.json)，核心结构：

```json
{
  "meta": { "source": "书名/课程名", "built": "2026-08-01", "status": "active" },
  "domain": "学科领域",
  "clusters": { "ch1": { "title": "第一章 标题" } },
  "items": [
    {
      "id": "ch1-1",
      "cluster": "ch1",
      "title": "知识点标题",
      "type": "definition",          // definition/concept/theorem/method/example/application/exercise
      "mode": "whitebox",            // whitebox(深究) / blackbox(工具)
      "source": "教材第X章 §Y 页码",
      "prerequisites": ["ch1-0"],    // 前置依赖（先学）
      "related": ["ch2-3"],          // 相关概念（横向联系）
      "note": "一句话解释（可选）"
    }
  ]
}
```

**新手建议**：

1. 优先用 **AI 建图谱**，生成后认真校对 5 分钟，比手写快十倍
2. 从 `examples/demo-math.json` 开始体验手动格式（5 个节点，覆盖概率公理→随机变量→期望→大数定律→中心极限定理）
3. **学一节建一节**：不要一次建完一本书；跟着学习进度增量维护
4. 图谱文件放到 `./bookmap/` 或 `~/.huoshu/bookmap/`（或用 `HUOSHU_BOOKMAP_DIR` 指定），图谱页侧边栏即可选择
5. AI 生成产物是「草稿」——保存后如发现错误，可重新生成或手动编辑 JSON

## 五、常见问题 FAQ ❓

**Q1：AI 建图谱需要什么？**
先配置 LLM（⚙️ 模型设置：DeepSeek Key 或 Ollama 本地模型）；选好 PDF 后点生成即可。没配置 LLM 时建图谱页会提示去设置。**推荐模型用 deepseek-chat**（非推理模型，结构化输出快且稳）；若用推理模型（如 deepseek-v4-flash）生成失败，切回 deepseek-chat 或直接重试。

**Q2：生成的知识点不准 / 太少？**
① 校对阶段手动改 type/mode、删多余项；② 每段上限 8 条，章节长会自动分段（生成慢是正常的）；③ 换个 LLM 模型试试（如 deepseek-chat 换更贵的模型）；④ 把 PDF 按章节拆分生成更细的图谱。

**Q3：检索页提示 Ollama 连不上？**
先确认 Ollama 已启动（`ollama list` 能列出模型）；再确认已 `ollama pull nomic-embed-text`。远程/容器环境用 `HUOSHU_OLLAMA_URL` 指到 Ollama 地址。

**Q4：不配置 LLM 能用吗？**
能。学习会话降级为模板引导，复习降级为关键词自动判分；图谱浏览、教材检索、间隔复习调度全部正常。配了 LLM 才有完整 Socratic 教学体验。

**Q5：检索结果不理想？**
① 把分块大小调小（更细粒度）重新入库；② 换更具体的问法；③ 同一问题换关键词再搜。

**Q6：Windows 上找不到 `~/.huoshu/` 目录？**
`~` = `C:\Users\你的用户名`。资源管理器地址栏直接粘贴 `%USERPROFILE%\.huoshu` 即可（需先运行过一次应用）。

**Q7：端口 8501 被占用？**
`huoshu --server.port 8600` 换端口。

**Q8：如何升级版本？**
```bash
pip install -U learning-agent
```

**Q9：我的教材 PDF 会上传/泄露吗？**
不会。所有数据只存本机 `~/.huoshu/`；向量化和检索都在本地完成（embedding 默认本地 Ollama）；只有学习会话的提问会发送给你配置的 LLM 提供商（DeepSeek/OpenAI 等，这是 AI 对话的正常机制）。

**Q10：图谱里的掌握度是怎么来的？**
初始 0.5，复习答题后按 IRT 2PL 模型更新：答错 -0.15 并回炉，答对 +0.10，高置信答错惩罚更大（hypercorrection 效应）。

## 六、常见问题排查速查表 🔧

| 症状 | 可能原因 | 解法 |
|---|---|---|
| `huoshu` 找不到命令 | 未安装 / venv 未激活 | `pip install learning-agent`；激活 venv |
| 启动后页面空白 | 端口冲突 | `huoshu --server.port 8600` |
| 检索无结果 | 未入库 / 集合未选 | 先入库；侧边栏选对集合 |
| 入库报错 | Ollama 未运行 / PDF 加密 | 启动 Ollama；换未加密 PDF |
| 学习会话回复模板化 | LLM 未配置 | 设置页填 API Key + 测试连接 |
| 连接 DeepSeek 失败 | 网络/代理 | 设置页填代理地址；确认 Key 正确 |
